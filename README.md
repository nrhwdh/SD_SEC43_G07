Installation Manual
1. Download the project source code from the GitHub link below.
2. Extract the folder into your *htdocs* directory (for XAMPP).
3. Open *phpMyAdmin*, create a new database named the_pearl.
4. Import the SQL file: DATABASE DUMP FILE V1.0 - G07_43.sql.
5. Run the system by typing:
6. user - http://localhost/the-pearl/the_pearl/index.php
7. admin - http://localhost/the-pearl/the_pearl/admin/login.php
